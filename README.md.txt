# Claude Chat Viewer

Локальный просмотрщик истории Claude Code. Python + Flask, без Docker и внешних API.

## Запуск

Требуется Python 3.9+.

```bash
cd claude_chat_viewer
python3 -m venv .venv
source .venv/bin/activate       # macOS / Linux
# .venv\Scripts\activate        # Windows
pip install -r requirements.txt
python app.py
```

Открой в браузере: http://127.0.0.1:5055

В поле сверху укажи `~/.claude`, полный путь к `.claude` или непосредственно к папке `projects`. Приложение рекурсивно ищет `*.jsonl` внутри каталогов проектов.

## Локальное хранение

У каждого проекта в списке есть кнопка **«Сохранить историю»**. Она сохраняет все чаты этого проекта в отдельный JSONL-файл в папке `history` рядом с `app.py`. Имя файла строится из названия проекта.

Чтобы дополнить архив из другой папки Claude:
1. Укажи путь ко второй папке `.claude` и нажми «Найти чаты».
2. Приложение объединит найденные диалоги с уже сохранённым архивом.
3. Нажми «Сохранить историю» у нужного проекта. Новые чаты и сообщения будут добавлены в локальный архив без повторов.

Локальный архив остаётся на компьютере и загружается при каждом сканировании. Исходные JSONL-файлы Claude не изменяются.

## Работа с диалогом

- Текстовые сообщения Claude и пользователя отображаются с форматированием Markdown.
- Вызовы инструментов и результаты соединяются в одну запись инструмента. Два и более вызова подряд сворачиваются в блок «Свернуто вызовов инструментов: N».
- У каждого сообщения и вызова инструмента есть кнопка удаления. Удаление сохраняется в локальном архиве; исходный файл Claude не меняется.
- Кнопка «Скопировать историю» копирует только текстовые сообщения в формате «Автор / Дата / Текст». Вызовы и результаты инструментов в копию не входят.
- Диалоги сгруппированы по проектам; группы можно сворачивать.

Сервер слушает только `127.0.0.1` и не использует внешние API.
